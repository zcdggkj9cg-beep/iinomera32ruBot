# AI Photo Studio — стартовый проект

Это начальная версия Telegram-бота на FastAPI + OpenAI API.

## Уже реализовано
- `/start`, `/help`, `/history`
- генерация изображения по текстовому запросу
- редактирование фото по подписи или следующему текстовому сообщению
- описание/анализ фото командой `/describe`
- сохранение текстовой истории в PostgreSQL
- Telegram webhook с проверкой секретного заголовка
- health-check для Render

## Важно перед коммерческим запуском
Это MVP для тестирования, а не готовая коммерческая платёжная система.
Пока НЕ реализованы Telegram Stars, тарифы, лимиты/кредиты, возвраты,
админ-панель, очередь задач, хранение готовых изображений и полноценная
защита от злоупотреблений. Не запускайте платные продажи до реализации и
тестирования этих частей.

Бесплатный Render может засыпать после простоя, а его файловая система
временная. Не используйте SQLite на Render для пользовательских данных.
Подключите PostgreSQL. Бесплатная БД Render имеет ограничения и срок жизни;
для реальных клиентов нужен надёжный платный datastore и резервные копии.

## Локальный запуск
1. Установите Python 3.11+.
2. `python -m venv .venv`
3. Активируйте окружение.
4. `pip install -r requirements.txt`
5. Создайте `.env` по примеру `.env.example` и заполните значения.
6. Запустите: `uvicorn main:app --reload`

Локально для теста можно не задавать `DATABASE_URL`: будет создан SQLite-файл.
Для Render обязательно используйте PostgreSQL.

## Развёртывание на Render
1. Создайте приватный GitHub-репозиторий `ai-photo-studio`.
2. Загрузите в него все файлы проекта.
3. В Render выберите New → Web Service → ваш репозиторий.
4. Build command: `pip install -r requirements.txt`
5. Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
6. Добавьте environment variables:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather
   - `TELEGRAM_WEBHOOK_SECRET` — длинная случайная строка (буквы/цифры/`_`/`-`)
   - `OPENAI_API_KEY` — секретный API-ключ
   - `PUBLIC_BASE_URL` — адрес сервиса, например `https://ai-photo-studio-xxxx.onrender.com`
   - `DATABASE_URL` — Internal Database URL вашей PostgreSQL в Render
7. После деплоя проверьте `https://ВАШ-СЕРВИС/health`.
8. При старте приложение автоматически зарегистрирует webhook в Telegram.

Не вставляйте токены в GitHub, README, переписку или исходный код.

## Команды
- `/start` — приветствие
- `/help` — подсказка
- `/history` — последние текстовые сообщения
- `/describe` — анализ ранее отправленной фотографии

## Текущие ограничения MVP
- Ожидает изображения JPG/PNG/WebP, но лучше присылать JPEG/PNG.
- Временное состояние ожидающей фотографии хранится в памяти процесса и теряется при перезапуске.
- Пока нет контроля расходов на пользователя и платёжной проверки.
- Генерация может занимать до пары минут.
